# Frontend Design Rules

All frontend work must feel intentionally designed for BG-GAMER.

## Avoid

- Generic AI-generated landing pages
- Excessive cards
- Three-column feature grids
- Purple gradient SaaS aesthetics
- Large rounded containers everywhere
- Repetitive icon-title-paragraph components
- Inter or system fonts as the main visual identity
- Centered hero sections unless explicitly requested
- Decorative blobs and meaningless glassmorphism
- Placeholder statistics displayed as real values

## Prefer

- Gaming-specific interface patterns
- Asymmetrical layouts
- Strong typography
- Discord and game-lobby inspired components
- Live community data as a visual element
- Clear section-to-section rhythm
- Purposeful motion
- Editorial composition
- Responsive layouts designed separately for mobile
- Visual browser verification after every major change

Before implementing a new page, propose at least three visually distinct directions.

Every frontend task must be inspected in a real browser at desktop and mobile widths before completion.
